# Блок управления котлом «Протон» — техническое описание

## Обзор

Блок управления котлом построен на микроконтроллере **ATmega8** и обеспечивает отображение температуры, управление уставкой и индикацию состояния котла.

---

## Аппаратная часть

### Микроконтроллер
- **ATmega8** — основной управляющий контроллер

### Сдвиговый регистр SN74HC164N
Последовательный сдвиговый регистр с 8 параллельными выходами (Q0–Q7). Используется для управления сегментами дисплея и отдельными светодиодами через всего **2 пина** ATmega:
- `DATA` — последовательные данные
- `CLK` — тактовый сигнал

Пин `/CLR` подтянут к VCC — сброс регистра не используется.

### Двухразрядный 7-сегментный дисплей
Отображает текущую температуру или уставку. Управляется через сдвиговый регистр:

| Бит (Q) | Сегмент |
|---------|---------|
| Q0      | a       |
| Q1      | b       |
| Q2      | c       |
| Q3      | d       |
| Q4      | e       |
| Q5      | f       |
| Q6      | g       |
| Q7      | dp (точка) |

### 8 индикаторных светодиодов
Подключены **параллельно** к тем же выходам Q0–Q7 сдвигового регистра через токоограничивающие резисторы. Показывают состояние котла (горелка, насос, авария, режим и т.д.).

### Транзисторные ключи (3 штуки)
ATmega управляет тремя группами через транзисторы (общие катоды):

| Пин ATmega | Транзистор | Группа              |
|-----------|------------|---------------------|
| PIN_A     | T1         | Разряд 1 дисплея (десятки) |
| PIN_B     | T2         | Разряд 2 дисплея (единицы) |
| PIN_C     | T3         | 8 индикаторных светодиодов |

### Кнопки управления (4 штуки)
Кнопки подключены к линиям Q0–Q7 через **развязывающие диоды**, что позволяет читать их состояние по тем же пинам что и выводить данные.

| Кнопка        | Функция                          |
|---------------|----------------------------------|
| `+`           | Увеличить уставку температуры    |
| `−`           | Уменьшить уставку температуры    |
| `Старт/Пауза` | Запуск и остановка котла         |
| `Программирование` | Вход в режим настройки      |

---

## Принцип работы дисплея — мультиплексирование

Все три группы (разряд 1, разряд 2, светодиоды) управляются **поочерёдно** с частотой ~100–300 Гц. Глаз воспринимает свечение как непрерывное.

```
Цикл мультиплексирования:
┌─────────────────────────────────────────────────────┐
│ 1. PIN_A = ON  │ Загрузить байт цифры десятков в регистр │ ~2мс │
│ 2. PIN_A = OFF │                                          │      │
│ 3. PIN_B = ON  │ Загрузить байт цифры единиц в регистр   │ ~2мс │
│ 4. PIN_B = OFF │                                          │      │
│ 5. PIN_C = ON  │ Загрузить байт состояний светодиодов     │ ~2мс │
│ 6. PIN_C = OFF │                                          │      │
│ Повторять...   │                                          │      │
└─────────────────────────────────────────────────────┘
```

Когда активен PIN_C — дисплей не светится. Когда активны PIN_A/PIN_B — светодиоды не светятся. Один сдвиговый регистр обслуживает всё устройство.

---

## Логика работы панели управления

### Нормальный режим
Дисплей показывает **текущую температуру** теплоносителя с датчика.

### Режим изменения уставки
```
Нажата "+" или "−"
    └── дисплей переключается на уставку
        └── повторные нажатия "+" / "−" меняют значение
            └── 3 секунды бездействия
                └── уставка мигает 3 секунды
                    └── возврат к отображению текущей температуры
```

Уставка сохраняется в **EEPROM ATmega8** — значение не сбрасывается при отключении питания.

### Режим программирования
Кнопка **«Программирование»** открывает доступ к расширенным настройкам: гистерезис, задержки, режимы работы.

## Схема подключения (упрощённо)

```
ATmega8
├── DATA ──────────────────────────→ SN74HC164N (pin 1,2)
├── CLK  ──────────────────────────→ SN74HC164N (pin 8)
│                                        │
│                              Q0–Q7 ────┼──→ сегменты a-g, dp (дисплей)
│                                        └──→ 8 светодиодов (через резисторы)
│
├── PIN_A ──→ транзистор T1 ──→ общий катод разряда 1
├── PIN_B ──→ транзистор T2 ──→ общий катод разряда 2
└── PIN_C ──→ транзистор T3 ──→ общий катод светодиодов

Кнопки: подключены к линиям Q0–Q7 через диоды (развязка)
/CLR сдвигового регистра: подтянут к VCC
```

## Перехват данных с помощью Arduino

Для мониторинга данных на шине можно подключить Arduino как пассивный наблюдатель:

```
ATmega8 (Протон)     Arduino
DATA ───────────────→ pin 2
CLK  ───────────────→ pin 3
PIN_A ──────────────→ pin 4
PIN_B ──────────────→ pin 5
PIN_C ──────────────→ pin 6
GND  ───────────────→ GND   ← обязательно!
```

Arduino читает байт по фронту CLK и по состоянию PIN_A/PIN_B/PIN_C определяет что именно передаётся — цифра первого разряда, второго, или состояние светодиодов. Байт декодируется в цифру по таблице сегментов.

> **Примечание:** если данные не читаются корректно — попробуй инвертировать логику (`!digitalRead(PIN_X)`), так как полярность зависит от типа транзистора в схеме (NPN/PNP).
